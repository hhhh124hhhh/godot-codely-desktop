CI 的安装测试只在一次性 GitHub-hosted Windows runner 上执行，会修改该测试机的快捷方式和安装注册；禁止在开发者本机直接执行。未签名模式只跳过签名断言，仍执行安装、Office 资源、启动、客户端与升级检查；签名模式继续强制验证安装器及所有 PE 的签名。

## 首批执行

先邀请 3–5 位愿意提供复现步骤的用户。每人只做一个能观察结果的小任务；按安装启动、模型配置、项目识别、工具执行、结果正确性记录首次阻塞点。修复阻断后，再请原用户使用新版本按同一步骤复测。

维护一个已脱敏的 Issue 列表，记录版本、系统、最短复现、影响和修复版本。邀请文案见用户指南；没有本 fork 群入口前不把上游社区二维码当作本项目种子群。

新版本必须新建版本号，不能覆盖已发布 tag。未签名早期包继续明确标记 unsigned；不承诺尚未验收的平台和功能。发布后复核 Releases 中的文件及哈希，再把该版本固定为首批用户下载入口。
