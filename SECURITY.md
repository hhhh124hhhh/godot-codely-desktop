# Security

## Reporting

Do not open a public issue for an unfixed vulnerability, and do not paste exploit details, API keys, tokens, or session files into issues, pull requests, logs, or screenshots.

This fork does not have a separate security mailbox. Report privately to the maintainer account [hhhh124hhhh](https://github.com/hhhh124hhhh) or, when the repository allows it, through GitHub private vulnerability reporting. Include the affected path, the version or commit, and enough detail to reproduce the problem on a temporary profile.

## What to expect

The maintainer will confirm receipt and keep the report private until a fix is available. User profiles, credentials, and sessions stay on the reporter's machine. A diagnostic report should not ask anyone to wipe a profile as the first step.

## Scope

This file covers code in this fork. DeepSeek Harness, Godot, and other upstream projects receive reports in their own repositories. Installers on dshdesktop.com are published by the upstream DSH Desktop project, not by this fork.
