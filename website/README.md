# Godot Codely 产品主页

参考 Tuanjie AI 官网的浅色、居中首屏与能力分段布局；配色采用品牌图标的蓝色（#2459d8）、淡蓝光晕和冷灰背景，使用 Godot Codely 自身的品牌与真实能力。场景与对话属于标注的交互概念演示，不是实际运行截图。

本目录是独立的静态宣传站，不参与 Electron / Harness 业务界面或启动协议。不新增前端依赖。

`/desktop.html` 为桌面工作台交互设计原型，提供项目总览、开发会话、项目 / 改动 / 验证面板、文件弹窗及深浅主题。它未接入实际项目、模型或引擎；所有示例状态均在界面标注。设计边界和落地顺序见 [桌面设计提案](../docs/godot-desktop-design.md)。

```sh
npm run website:preview
```

打开 `http://127.0.0.1:4173`。可通过 `WEBSITE_PORT` 指定本地端口；修改后重新运行预览命令。

```sh
npm run website:build
```

构建结果在忽略目录 `.build/website/`，可以部署到任意静态托管服务。主页使用相对资源路径，可放在域名根目录或子目录。品牌图标从唯一源 `build/brand-mark.svg` 构建复制，不在本站重复维护。

主页的发布、文档、开源和问题反馈链接均指向本仓库。发布按钮打开 Releases 列表，不假定某个平台已有安装附件。本站没有登录、收费或收集用户数据的表单。
