# Code of conduct

This repository is open to people using and changing the DSH Desktop fork, including the Godot path. Participants are expected to:

- Discuss the change, the failure, and the evidence. Leave personal attacks out of issues, pull requests, and reviews.
- Accept a no when a change is out of scope, and say so plainly when closing one.
- Keep other people's private data out of the repository. That includes API keys, session files, and machine-specific paths from a real profile.
- Credit upstream and third-party licenses that are already in the tree. Do not strip copyright notices.

Maintainers may edit or close comments and pull requests that break these rules. Report a conduct problem the same way as a security issue: privately, as described in [SECURITY.md](SECURITY.md), and without posting someone else's personal data.
